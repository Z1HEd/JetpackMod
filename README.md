# JetpackMod

JetpackMod is a mod for 4D Miner that adds a jetpack item with multiple flight modes and fuel types.

Made using the [4DModding framework](https://4d-modding.com/) and generated from the [official mod template](https://github.com/4D-Modding/4dmod-example).

Currently singleplayer-only. Requires 4DKeybinds.

## Features

- Jetpack item with 3 modes:
  - Flight
  - Hover
  - Off
- Flight mode for upward flight
- Hover mode that maintains player height
- Two fuel types with different efficiency and speed:
  - Biofuel
  - Deadly Fuel
- Fuel switching and tank emptying
- Custom crafting materials and progression

## Default controls

- `F` — switch jetpack mode
- `R` — switch fuel type
- `Z` — empty fuel tank
- `SPACE / SHIFT` — move up or down while hovering
